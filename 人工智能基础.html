模块一 基础概念

先建立术语坐标系：分清 AI、Agent、Harness 三者的层次关系。

AIArtificial Intelligence · 人工智能

让机器模拟人类智能完成感知、推理、学习、决策等任务的技术总称。

涵盖机器学习、深度学习、自然语言处理等分支；大语言模型（LLM）经海量文本训练获得理解与生成能力，是当前 AI 最核心的形态。

Agent智能体

以 LLM 为"大脑"，围绕目标自主完成感知 → 规划 → 行动 → 反思循环的 AI 系统。

能调用工具（搜索、执行代码、读写文件），把大任务拆成多步并持续迭代直至完成——关键在于"自主做事"，而非一问一答。

Harness执行框架 · 智能体脚手架

包裹模型的工程外壳，负责循环控制、工具执行、上下文管理与权限安全，让模型的"想法"真正落地。

模型负责思考，Harness 负责执行：运行工具调用、把结果回传、判断何时结束。类比：模型是引擎，Harness 是底盘与方向盘——如 Trae、Claude Code、Cursor 等编码智能体的执行框架。

关系链：AI 是领域 → LLM 是引擎 → Agent 是会自主干活的系统 → Harness 是让它跑起来的框架

模块二 文本表示 · 词元 Token

理解「文字」如何变成模型能计算的「数字」——这是所有大模型的入口。

词元 Token · 从文字到向量

读法：模型不直接读「字」或「词」，而是先切成词元，再把每个词元换成整数 ID，查嵌入表得到向量后才开始计算。

词元是什么

  • 定义
    模型处理文本的最小单位，是「文字」与「数字」之间的桥梁
  • 谁切分
    由分词器 Tokenizer 完成，常见算法：BPE / WordPiece / SentencePiece
  • 切分规律
    高频词整体成一个词元，生僻词被拆成子词；标点、空格、数字常切得很碎

同一个词在不同分词器下可能切成不同词元，没有统一答案。

为什么重要

  • 上下文窗口
    常说的 128K，单位是词元数，不是字数
  • API 计费
    按输入 + 输出的词元总数收费
  • 生成速度
    用 tokens/s 衡量，越快越流畅

粗略换算（估算）：英文约 0.75 个单词 ≈ 1 词元；中文约 1 个字 ≈ 1 词元。

常见误区

  • 不等于字或词
    子词、标点、空格都可能是独立词元
  • 字符数 ≠ 成本
    计费按词元，不按字符
  • 特殊字符更费
    emoji、生僻字可能占多个词元

记住一句话：模型眼中的世界，是按词元计量的。

模块三 网络结构

分清两类经典结构：CNN 擅长空间（图像），RNN 擅长时序（序列）。

卷积神经网络 CNN · 数据流水线

读法：图像经「卷积 → ReLU → 池化」逐层堆叠，特征由简单到复杂（边缘 → 纹理 → 部件 → 整体），最终由全连接层输出分类结果。

CNN 核心组件

  • 卷积层 Conv
    卷积核（如 3×3）在输入上滑动做乘加运算，提取边缘、纹理等局部特征
  • 激活函数 ReLU
    f(x) = max(0, x)，引入非线性，让网络能拟合复杂模式
  • 池化层 Pooling
    最大池化取窗口内最大值，压缩尺寸、保留显著特征、抗轻微偏移
  • 全连接层 FC
    把特征图展平后汇总，输出各类别得分

CNN 三大特性

  • 局部感受野
    每个神经元只看一小块区域，符合图像"局部相关"的先验
  • 权值共享
    同一个卷积核扫遍全图，参数量远小于全连接网络
  • 平移不变性
    目标移动位置后，同一组卷积核仍能捕捉到相同特征

与全连接网络相比：参数更少、训练更快、更适配图像结构。

尺寸公式与经典网络

  • 输出尺寸
    O = (N − K + 2P) / S + 1
  • 符号说明
    N 输入边长 · K 卷积核 · P 零填充 · S 步幅
  • 经典演进
    LeNet → AlexNet → VGG → ResNet（残差连接）
  • 典型应用
    图像分类、目标检测、人脸识别、医学影像

循环神经网络 RNN · 按时间步展开

读法：同一组参数在所有时间步共享；隐藏状态 h 沿横向箭头传递，把「上文信息」带给下一步——这就是 RNN 的记忆。y₁–y₄ 可逐步输出，也可只在末步输出。

RNN 核心机制

  • 隐藏状态 Hidden State
    h_t = f(W_x·x_t + W_h·h_{t-1} + b)，充当"记忆"，携带历史信息前进
  • 按时间展开
    同一个单元在 t = 1…T 逐步复用，等价于一条沿时间的深链
  • 参数共享
    W_x、W_h 在所有时间步复用，参数量与序列长度无关
  • 输出方式
    可每步输出 y_t（逐词生成），也可只在末步输出（序列分类）

局限与改进

  • 梯度消失 / 爆炸
    长序列反向传播时梯度连乘衰减或放大，难以学习长距离依赖
  • LSTM 长短期记忆
    遗忘门 / 输入门 / 输出门，选择性地记住与遗忘
  • GRU
    简化为更新门 + 重置门，参数更少、效果接近
  • 走向 Transformer
    自注意力可并行建模长依赖，已成 NLP 主流架构

CNN vs RNN · 应用

  • 擅长数据
    CNN 吃"空间邻域"（图像），RNN 记"时间前后"（序列）
  • 典型应用
    文本生成、机器翻译、语音识别、时间序列预测
  • 记忆口诀
    CNN 看"局部形状"，RNN 记"上下文顺序"

提示：如今 NLP 任务多被 Transformer 取代，RNN 更常出现在轻量序列与时序预测场景。

模块四 生成与运行

看懂一次生成要经过哪些环节，以及「训练」与「推断」的分工和可控的采样参数。

生成系统 · 六个环节

读法：把「需求」变成「产物」的六步链路——前三步理解意图并生成内容，第四步决定随机程度，后两步把内部表示解码为可交付成品并收集反馈。文本、图像、语音系统的环节名称略有差异，骨架一致。

训练 Training · 循环

  • ① 前向传播 Forward
    输入过网络，算出预测结果
  • ② 计算损失 Loss
    预测与真实标签比较，量出误差
  • ③ 反向传播 Backward
    按链式法则求各参数的梯度
  • ④ 更新参数 Update
    优化器（SGD / Adam）按梯度调整权重

反复迭代直到损失收敛；需要大规模数据与算力，通常离线批量进行。

推断 Inference · 流程

  • 输入 → 前向传播 → 输出
    只用训练好的参数做一次前向计算，不更新权重
  • 目标
    低延迟、低成本、输出稳定
  • 常见优化
    量化、蒸馏、剪枝、KV 缓存、批处理

训练一次、推断千万次——线上体验主要取决于推断的效率。

训练 vs 推断 · 对比

维度 训练 Training 推断 Inference
核心目标 从数据中学出参数 用已有参数算出结果
参数更新 反向传播 + 优化器持续更新 冻结不变
数据需求 大批量、多轮迭代 单条或小批量输入
计算特点 高算力、耗时长、可离线 低延迟、在线、成本敏感
关键优化 分布式并行、混合精度 量化、蒸馏、KV 缓存
延迟要求 不敏感，重吞吐 敏感，重响应速度

一句话：训练是「学」，推断是「用」；训练贵在算力与数据，推断贵在延迟与成本。

采样策略

  • 贪心 Greedy
    每步取概率最大的候选，最稳但易重复、缺创意
  • 束搜索 Beam Search
    并行保留多条候选路径择优，质量高但慢、偏保守
  • 随机采样
    按概率分布抽样，输出多样但可能跑题

确定性策略求稳，随机策略求变；随机程度由下面几个参数控制。

三个核心参数

  • Temperature 温度
    缩放概率分布：T→0 趋于贪心（确定），T 越大分布越平、越随机
  • Top-k
    只在概率最高的 k 个候选里抽样，砍掉长尾噪声
  • Top-p 核采样
    从累计概率达到 p 的最小候选集里抽样，比 Top-k 更自适应

常用组合：温度 0.7 + Top-p 0.9；要可复现就把温度调低并固定随机种子。

其他控制参数

  • max_tokens
    限制生成长度上限，控制耗时与成本
  • Repetition penalty
    惩罚已出现的 token，抑制复读
  • Seed / Stop
    固定种子使结果可复现；命中停止符提前结束
  • 图像生成专用
    Guidance scale（CFG）控制贴合提示词程度，Steps 平衡去噪质量与耗时
模块五 模型评估

掌握混淆矩阵与四大指标，学会判断一个模型「好不好」。

混淆矩阵（2×2）

预测：正例 预测：负例
实际：正例 TP 真正例 FN 假负例
实际：负例 FP 假正例 TN 真负例

记忆口诀：先看真假（预测对不对），再看正负（预测成什么）。

完整公式（N = 样本总数）

  • 准确率 Accuracy
    Accuracy = (TP + TN) / (TP + FP + TN + FN)
  • 精确率 Precision
    Precision = TP / (TP + FP)
  • 召回率 Recall（灵敏度）
    Recall = TP / (TP + FN)
  • F1 值
    F1 = 2·P·R / (P + R)

类别不平衡时 Accuracy 可能虚高，应重点看 Precision、Recall 与 F1。
